# 검증 결과

## 1. 이 제출물의 Docker 이미지로 RTX 4090에서 실행 (`scripts/validate.sh`)
- 환경: RTX 4090, 컨테이너 torch 2.7.1+cu128.
- 결과 원문: `validation/result/validation.json`

| 항목 | 결과 |
|---|---|
| FLOPs (FlopCounterMode, 1회 forward 전체) | 743,777,233,600 — 제출 `__flops__`와 같다 |
| 1회 forward 시간 (BF16, 전처리 제외, warmup 20 / 100회) | 중앙값 **31.2 ms**, p95 33.1 ms → 시간 벌점 ×1.0 |
| 학습 fixture 8 clip vs 원 학습 서버(B200) 예측 | 최대 좌표 차이 중앙값 2.2 mm, 최대 4.2 mm, 선택 후보 8/8 일치 |
| 테스트 20 clip vs **실제 제출 파일** | 최대 좌표 차이 중앙값 1.5 mm, 선택 후보 18/20 일치, 가중 L2 평균 1.4 mm |

- 선택 후보가 달라진 2 clip의 가중 차이는 0.3 mm와 14.7 mm다.
- 5초 끝점이 goal과 거의 같은 거리인 후보가 둘 있을 때, GPU 종류별 BF16 차이로 선택이 바뀐다.
