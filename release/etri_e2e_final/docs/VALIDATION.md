# 검증 결과

## 1. 이 제출물의 Docker 이미지로 RTX 4090에서 실행 (`scripts/validate.sh`)
- 환경: NVIDIA GeForce RTX 4090, 컨테이너 torch 2.7.1+cu128
- 결과 원문: `validation/result/validation.json`

| 항목 | 결과 |
|---|---|
| FLOPs (FlopCounterMode, 1회 forward 전체) | 743,777,233,600 (제출 `__flops__`와 같습니다) |
| 1회 forward 시간 (BF16, 전처리 제외, warmup 20회 후 100회) | 중앙값 **30.8 ms**, p95 31.3 ms (시간 가중치 ×1.0) |
| 학습 clip 8개, 학습 서버(B200) 예측과 비교 | 좌표 최대 차이 중앙값 2.2 mm, 최대 4.2 mm, 선택 후보 8/8 일치 |
| 테스트 clip 20개, **실제 제출 파일**과 비교 | 좌표 최대 차이 중앙값 1.5 mm, 선택 후보 18/20 일치, 가중 L2 평균 1.4 mm |

선택 후보가 달라진 2개 clip의 가중 차이는 0.3 mm와 14.7 mm입니다. 5초 끝점과 목표점의 거리가 거의 같은 후보가 2개 있을 때, GPU 종류별 BF16 연산 차이로 선택이 바뀌는 경우입니다.

## 2. 학습 재현 (학습 서버 B200, 같은 코드와 seed)
| 재현 항목 | 원래 | 재현 |
|---|---:|---:|
| 3단계만 재학습, held-out 모델 (검증 scenario 점수) | 0.130237 | 0.130324 |

| 연쇄 재학습 모델의 테스트 예측, 제출본과 비교 | — | 평균 2.3 cm |

- 학습 시작 시점의 값은 비트 단위로 일치합니다.
- 학습 중간에는 곡선이 벌어졌다가 종료 시점에 수렴합니다. 원인은 BF16과 비결정적 CUDA 누적 연산입니다.
- 2단계 사전 점검(smoke) 결과는 다음과 같습니다.

  - BN 통계 불변
  - ego 상태를 바꿔도 motion·상태 예측 변화 0.0
