## 입력 조건과 규정 설명

A2부터 제공된 past/current pose로 계산한 status5를 학습·추론 입력으로 사용한다.
A2는 shared scene query, A3는 이에 더해 FPN 채널 gate를 조건화한다. A3의 motion/state
출력은 제공 status의 영향을 받으므로 Q10의 영상 단독 추론으로 설명할 수 없다.
Q6/Q7의 허용 설명을 근거로 설계했으며 최종 규정 판단은 코드 심사다.

| 검사 | A2 PREFIX | A3 PREFIX |
|---|---:|---:|
| 정상 | 0.164281 | 0.149289 |
| 영상만 다른 session으로 교체 | 1.082452 | 0.894936 |
| 영상 전체 단색 | 2.418113 | 2.118935 |
| status만 다른 session으로 교체 | 0.391047 | 0.718751 |

정상 입력은 원본 terminal prediction과 좌표 오차 0으로 재현됐다. 과거~현재 31개 pose만
남기고 다섯 status를 다시 계산했을 때 전체 1,998행이 원래 입력과 정확히 같았다.
이는 영상 의존성과 미래 pose가 필요하지 않다는 근거이며, 규정 통과 인증은 아니다.
자세한 구조와 검사 조건은 `COMPLIANCE_AND_CHANGES_20260918_KO.md`에 기록했다.

## 기록 범위

`records_20260918/runs/`는 FRONT/SIDE/scalar/두 계수/AUX/denoise/status warmup,
A2/A3 direct, factorization 중단, smoke, FULL 및 OOF의 총 24개 실행 단계를 포함한다.
원래 예산을 끝내지 않은 단계는 평가 여부와 마지막 학습 로그를 구분해 표시했다.
A3-FP-VA의 마지막 로그는 step 600이다. 과거 문서의 350은 중간 확인 시점이었다.

학습 설정·곡선·평가 요약·검사 코드와 결과는 Git에 보존한다. 원본 checkpoint와 prediction
배열은 서버에 보존하고 주요 파일의 SHA256을 색인에 기록한다. 다음 우선순위는 A3 seed 재현,
별도 A3 FULL, strong-base oracle 및 new107 OOF 진단이며 새 학습은 아직 시작하지 않았다.
