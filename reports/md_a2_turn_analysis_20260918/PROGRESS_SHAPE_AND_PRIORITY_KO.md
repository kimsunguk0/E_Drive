# 진행량과 회전 모양의 구분 / 사용자 우선순위 (2026-09-18)

사용자 지시에 따라 회전·command 전용 실험은 후순위로 둔다.
기존 A2 FULL, BASE/MH4, SIDE-SCENE 순서를 유지한다.
일반 주행을 개선하면서 회전에서도 함께 개선되는 부분을 본다.

## 확정한 것과 미확정인 것

기존 그림의 동일한 MH4 step17,130 저장 예측에서, 모델의 누적 진행거리 s_pred까지
GT의 6점 궤적을 구간별 직선으로 보간해 위치를 비교했다.
GT 궤적 범위를 넘어서는 점은 제외한다. 좌방향/우방향 그룹의 PREFIX 가중치 중
각각 97.56%/99.10%가 비교 가능하다.

p_pred(t)-p_gt(t)
= [p_pred(t)-p_gt_curve(s_pred(t))]
+ [p_gt_curve(s_pred(t))-p_gt(t)]

왼쪽 항은 실제 위치 오차, 오른쪽은 같은 진행거리에서의 곡선 차이와 진행량 차이다.
벡터는 더해지지만 각 벡터 길이를 더하면 PREFIX가 되는 것은 아니다.
보간된 6점 경로의 출력 진단이며, 인식·학습 원인을 식별하는 인과 실험은 아니다.

| 같은 그림의 예시 | GT 총 진행거리 | 예측 총 진행거리 | 동일 거리에서 경로 차이 |
|---|---:|---:|---:|
| 좌회전 중앙 예시 (row94645) | 15.134m | 14.642m | 1.846m |
| 좌회전 최대오차 예시 (row94655) | 15.546m | 14.176m | 2.014m |
| 우회전 중앙 예시 (row36430) | 20.621m | 20.370m | 0.983m |
| 우회전 최대오차 예시 (row41690) | 18.176m | 14.975m | 0.185m |

이 예시들은 이전에 선택한 각 그룹의 중앙/최대오차 사례를 재사용했다.
최소 공통 진행거리에서 GT와 예측 경로를 모두 보간했다. 시간별 공식 점수와 다른 진단값이다.
특정 사례의 형태를 전체 회전에 일반화하지 않는다.

동일 유효점에서 가중 평균 곡선 차이/진행량 차이 크기:
- 좌방향 41행: 0.2036m / 0.2466m.
- 우방향 161행: 0.0861m / 0.1953m.
두 수치를 비율로 나눠 인과 기여율이라고 부르지 않는다.

확정할 수 있는 것은, 회전 오차가 모두 진행량 부족만으로 설명되지는 않는다는 점이다.
일반 진행량 개선이 일부 회전에도 도움이 될 여지는 크다.
공통 scene 인식 개선은 진행량과 경로 모양 양쪽에 영향을 줄 수 있다.
하지만 일반 주행 점수가 내려가면 회전 모양도 자동으로 해결된다는 보장은 없다.

아직 확정하지 못한 것은 모양 오차가 영상의 차선/교차로 근거, goal 조건의 활용,
학습 표본/손실, decoder 표현 중 어디에서 주로 발생하는지다.
command 부재를 원인으로 확정하지 않고, 회전 시점 지연과 곡률 부족도 단일 원인으로 구분하지 않는다.
이를 확인할 별도 intervention 실험은 이번에 하지 않는다.
