# MotionDrive V2 진단 정리 — 2026-09-09

학습 없이 기존 체크포인트에서 측정한 진단들이다. 여섯 개의 가설을 기각했고
두 개의 사실이 남았다. 모든 수치는 grouped tune1998, 공식 D3
(t=0.5…3.0 s 6점, 가중치 `[11,11,5,5,2,2]/36`)이다.

절제(ablation) 수치는 모두 **학습 분포 밖** 입력에 대한 반응이므로 의존도의
상한이지 깨끗한 인과 분해가 아니다. final136은 어디에서도 선택·학습·평가·분석
하지 않았고, tune 라벨로 학습하거나 모델을 고르지 않았다.

## 1. 오차 분해 — 남는 사실 ①

기준 체크포인트 `pv_screen_b0_direct_last2000`, D3 **0.293932**.

| 항목 | 값 |
|---|---|
| cross-track(경로 모양) 가중 오차 | 0.1331 |
| along-track(타이밍) 가중 오차 | 0.2023 (**60%**) |
| 종:횡 RMS | 83 : 17 |
| 모델 자기 경로 + GT 호길이 | **0.0765** |
| 초기속도 성분만 램프로 제거 | 0.1506 |
| t=0.5 오차 중 순수 종방향 비율 | **98%** (지표 가중치 30.6%) |
| corr(0.5 s 변위 오차, 3 s 호길이 오차) | 0.713 (R² 0.509) |

경로 기하는 사실상 해결됐고 남은 것은 타이밍이며, 타이밍은 초기속도와
가감속 프로파일이 대략 반반이다.

`controlflow_b0_direct_last4000`(D3 0.280640)에서도 같은 구조다:
cross 0.1243 / along 0.1914.

## 2. 입력 의존도 — 남는 사실 ②

같은 체크포인트, 평가 시점에만 입력을 바꿨다.

| 조건 | D3 | occ IoU | lane IoU |
|---|---|---|---|
| 영상 O + status O | 0.2939 | 0.435 | 0.494 |
| **영상 X(단색) + status O** | **4.2359 (×14.4)** | 0.138 | 0.057 |
| 영상 O + status X | 0.5628 (×1.9) | 0.434 | 0.494 |
| 영상 X + status X | 4.1096 | 0.137 | 0.061 |

운영국 기준(영상의 실질 기여)은 **큰 차이로 충족**한다.

`controlflow_b0_direct_last4000`에서 goal만 0으로:

| | goal O | goal=0 | 배율 |
|---|---|---|---|
| D3 | 0.2806 | 5.0457 | ×18.0 |
| cross-track | 0.1243 | 0.1409 | **×1.13** |
| along-track | 0.1914 | 4.9952 | **×26.1** |

**goal은 경로 모양이 아니라 거리(타이밍)를 떠받친다.** `goal=0`은 "목적지가
현재 위치"라는 적대적 입력이므로 ×26은 상한이다.

provided status5는 gt_state와 사실상 동일하다(vx MAE 0.0089, corr 1.0000).
A2에서의 실측 이득은 **0.0072**(provided 0.310104 vs zero 0.317294, 1 시드)로
P1·P3에서 쓴 -0.010 임계값에 미달한다. 의존(×1.9)은 정보 가치가 아니라
query 델타에 대한 co-adaptation으로 보인다.

## 3. 기각된 가설 여섯 개

**① aux state head가 planner의 병목이다** — 기각.
`state_hat` vx MAE 1.015인데 plan 첫 점이 함의하는 v0는 MAE 0.277(std 0.381).
planner는 scene·motion을 직접 받으므로 state token은 병목이 아니다.
두 오차의 상관은 0.586.

**② 시간축 softmax collapse가 속도 정보를 파괴한다** — 기각.
frozen 표현 선형 프로브: collapse 이후 1.0499 / **collapse 이전 per-timestep +
명시적 dt 1.0580** / 출하 헤드 1.0127. 차이 없음.

**③ goal이 타이밍의 정답지다** — 부분 기각.
goal 단독 3 s 호길이 예측 MAE 0.820 (모델 0.558). ego+goal 결합이라야
0.25로 떨어진다. goal 단독 재타이밍은 0.4365로 악화.

**④ correlation 탐색창이 포화했다** — 기각.
radius 2/4/8에서 soft-argmax 변위 0.11 / 0.24 / 0.34 셀, **창 경계 도달 0%**.
포화가 아니라 cost volume이 평평하다.

**⑤ BEV에서는 정합된다** — 기각.
BEV 셀 1.25×1.33 m, 0.5 s 변위 4.2셀로 기하 조건은 충분한데,
±14셀 상관 측정 변위 **0.34 m** (실제 5.27 m), corr **−0.200**.

**⑥ 공개 flow 모델이 metric v0를 준다** — 기각.
순방향 검증(참 ego 운동이 만들 흐름 vs 측정 흐름), 노면 픽셀:

| 모델 | 해상도 | corr u | corr v | 스케일 u / v |
|---|---|---|---|---|
| raft_small C_T | 216×384 | 0.651 | 0.266 | 0.348 / 0.176 |
| raft_small C_T | 432×768 | 0.731 | 0.386 | 0.475 / 0.291 |
| raft_large KITTI | 216×384 | 0.776 | 0.434 | 0.441 / 0.223 |
| raft_large KITTI | 432×768 | 0.252 | −0.082 | 0.236 / −0.106 |

전진 성분(v축)이 실제의 18~29%로만 측정된다. 차선 표시가 진행 방향과
나란해 생기는 조리개 문제와 노면 저텍스처, 반해상도 과거 프레임이 원인으로
일관된다. RAFT 자체는 정상이다(self-flow 0.043 px).

**한계**: ⑥은 **노면 픽셀만** 검정했다. 길가 구조물은 훨씬 잘 구속되지만
지면 평면이 아니라 깊이가 필요하다(DF-VO/DROID급). 또한 사전학습 모델의
zero-shot이며, 이 데이터로 학습한 대응 분기는 다를 수 있다.

두 후보 arm 모두 게이트 실패. 다만 분해하면:

| | flow | control |
|---|---|---|
| tune v0 MAE | 0.2638 | 0.2638 |
| v0 최상위 십분위(MAE 0.016)의 D3 | **0.1434** | 0.1473 |

step 2000 → 4000에서 v0는 0.283 → 0.264(7%)로 정체한 반면
v0-무관 바닥은 0.2226 → 0.1434로 크게 개선됐다. **가속 프로파일은 진전했고
병목은 v0 하나로 좁혀졌다.** flow arm 회귀식 `D3 = 0.870·|v0err| + 0.059`
기준 direct와 동률이 되려면 v0 MAE ≤ 0.254가 필요했다(실측 0.264).

## 5. 남은 판단

- 경로 기하는 천장(0.068)에 가깝다. 남은 것은 타이밍이다.
- 타이밍의 초기속도 절반은 **대응 측정으로는 접근 불가**하다(위 ④⑤⑥).
  현재 모델의 v0 0.264는 장면 맥락·goal·status에서 오며 대응 기반으로
  얻을 수 있는 값보다 한 자릿수 정확하다.
- 나머지 절반(가감속 의도)은 신호등·선행차 인식 문제이고, 챌린지가 실제로
  요구하는 능력이다. 십분위 바닥 0.143이 경로 천장 0.068의 2배로 여지가 있다.
- 개입과 무관하게 학습량은 계속 점수를 내렸다. 4,000 update 연속학습만으로
  0.2939 → 0.2806(−0.0133). 누적 학습은 아직 약 4~5 에폭에 불과하다
  (1 에폭 = 3,425 update; 측정 1.08 step/s에서 53분).
