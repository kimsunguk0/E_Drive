# E1-EXP-LEN 결과 — `IMPROVES_INCLUDING_NORMAL_DRIVING`, 다만 작다

- arm: `E1-EXP-LEN-s0`, 구간 길이 L1 auxiliary λ=0.25를 기존 loss에 **더함**. D3 loss 불변.
- control: 기존 `E1-EXP`. 같은 R0 초기값, 같은 Tplus(row SHA `e20e4541…`), 20,554 update,
  seed 0, 같은 LR·schedule·BN·flip·time·command OFF.
- **전 구간 sample-order digest가 control과 bitwise 동일**(`1ea9c7e77b5bbafb9…`, 20,550 step).
  초기 구간뿐 아니라 끝까지 같은 순서로 같은 데이터를 봤다. 완전한 한 변수 대조다.

## 2. 다섯 조건 — 전부 개선, signed 편향이 전부 0 쪽으로

가속·감속을 합치지 않는다(부호가 반대라 상쇄된다).

**다섯 조건 모두 D3가 내려갔고, 다섯 signed 편향이 모두 절대값으로 줄었다.**
편향의 부호가 반대인 가속(−)과 감속(+)이 **각각** 0 쪽으로 움직였다 —
전체 평균을 맞추는 방향으로 민 것이 아니라는 증거다.

다만 이동폭은 4–5% 수준이다(예: 정지 유지 +0.3445 → +0.3289). 편향의 크기 자체는 남아 있다.
