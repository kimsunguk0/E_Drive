# E1-EXP-LEN 사전 고정 판정 기준

**결과를 보기 전에 적는다.** 학습 중 λ·sampler·stop weight·history를 바꾸지 않는다.
이 run은 λ=0.25의 효과를 끝까지 읽는 실험으로 남긴다.

- control: 기존 `E1-EXP` (같은 R0 초기값, 같은 Tplus row SHA `e20e4541…`, 20,554 update,
  seed 0, 같은 LR·schedule·BN·flip·time·command OFF). step 1·50의 sample_order_sha256이
  bitwise 일치함을 확인했고, **종료 시 전체 sample-order digest도 기록한다.**
- 추가 본 학습은 이 1회뿐이다. λ sweep을 하지 않는다.

## 판정의 중심

**실제 XY의 V0 D3**다. 보조 loss 값이나 오차 분해 비율로 판정하지 않는다.

**공통성분 '비율'의 하락을 성공으로 보지 않는다.** 분모가 함께 움직이므로, 평균 성분의
절대 크기가 줄어도 잔차가 더 크게 줄면 비율은 오히려 오를 수 있다. 절대값으로 읽는다.

## 함께 볼 항목 — 다섯 조건을 반드시 분리한다

가속과 감속은 signed 편향의 부호가 반대(−0.0742 / +0.0525)라 합치면 상쇄된다.
정지 유지(+0.3445)와 출발(+0.2161)도 크기가 다르다. 통합 그룹은 요약용으로만 쓴다.

| 지표 | 확인할 것 |
|---|---|
| 전체 V0 D3 | 0.225592보다 실제로 낮은가 |
| **정속** D3·구간 길이 MAE | 오차 예산 62.1%인 일반 주행이 좋아지는가 |
| **정지 유지** D3·signed b (+0.3445) | 과도한 이동량이 줄어드는가 |
| **출발** D3·signed b (+0.2161) | 줄면서 출발을 과도하게 늦추지는 않는가 |
| **가속** D3·signed b (−0.0742) | 덜 붙이는 편향이 완화되는가 |
| **감속** D3·signed b (+0.0525) | 덜 줄이는 편향이 완화되는가 |
| v0 < 0.5 m/s 밴드 (131행, +1.049 m) | 이 밴드의 signed 편향이 실제로 줄어드는가 |
| mean\|b\| 절대값 (전체 0.1469) | 절대 크기가 줄어드는가 |
| 방향 오차 · 시점별 L2 | 길이를 맞추며 방향이나 특정 시점을 악화시키지 않는가 |
| train probe 대 V0 | train 길이 오차만 좋아진 것이 아닌가 |

## 사전 분기

| 결과 | 다음 행동 |
|---|---|
| 정속 포함 V0 D3 개선 | seed 확인 후 채택 검토 |
| 정지·출발만 개선 | 개선분은 평가하되 일반 주행 motion 관측 문제는 남긴다 |
| train만 개선 또는 V0 그대로 | **λ를 올리지 않는다.** 이 설정의 효과 미확인으로 닫고, 최근 temporal 관측·matching 정밀도 대조로 이동 |
| 방향·출발 악화 | 길이 항의 부작용으로 기록하고 기존 EXP 유지 |

부분적 결과 주의: 정지 유지만 좋아지고 출발·가속이 나빠지면 모델이 전반적으로 덜 움직이게
된 것일 수 있다. 전체 D3와 그룹별 손익을 함께 본다.

## 하지 않는 것

- H를 열지 않는다.
- clip별 수동 보정 규칙을 만들지 않는다.
- "정지 확률이 높으면 궤적 0 고정" 같은 처방으로 넘어가지 않는다.
- 관측 실험(H6-NEAR / H6-LONG, matching 해상도)은 이 결과 이후이며, 그때도
  **프레임 추가와 matching 해상도 변경을 한 번에 하나씩만** 바꾼다.
- 장기 history의 가능성은 이번 결과로 닫히지 않는다.
